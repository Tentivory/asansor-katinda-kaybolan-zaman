# Asansör Katında Kaybolan Zaman

> Bu depo, asansörlerin yalnızca mekân değil zaman da çaldığını resmen kabul eden ilk idari protokoldür.

## Resmi amaç

Bir düğmeye basarsınız. Asansör sizi katlara değil, takvimin kör noktalarına götürür. Bu yazılım o kaybı belgeler, damgalar ve size bir tutanak basar. İtiraz mercii yoktur. Çay ocağı diplomatik bölgedir.

## Kurulum (abartılı ciddiyetle)

1. Python 3.10+ bulun. Yoksa asansör zaten sizi bekletir.
2. Bu depoyu klonlayın.
3. Çalıştırın:

```bash
python asansor.py 4
```

Argüman vermezseniz yazılım sizi 3. kata, yani kimsenin gelmediği toplantı odasına gönderir. Bu bir özelliktir.

## Bilimsel dayanak

Yok. Ama evrak var. Evrak varsa gerçeklik vardır. Bu cümle bir yönetmelik maddesi gibi duruyor diye doğru olmaz; yine de tutanakta durur.

## Kat haritası (kısmi)

| Düğme | Resmi ad |
|------:|----------|
| -2 | arşiv bodrumu |
| -1 | kedi mama deposu |
| 0 | zemin, yani yalan dünya |
| 4 | çay ocağı diplomatik bölgesi |
| 5 | çatı ve rüzgâr vergisi |

## Sorumluluk reddi

Bu yazılım sizi gerçek bir asansörde mahsur bırakmaz. Yalnızca zamanınızı belgeler. Zaman belgelenince geri gelmez.
